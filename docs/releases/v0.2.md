# VPS Linux v0.2

VPS Linux now has a source-controlled Debian image build system, replacing the manual assembly used for v0.1.

## What's new

- mmdebstrap bootstrap using signed official Debian Trixie repositories.
- GPT, a 512 MiB EFI System Partition, ext4 root and removable UEFI GRUB in an 8 GiB standalone QCOW2.
- SHA256, exact package manifest and source/build metadata alongside the image.
- cloud-init creates the key-provisioned `debian` user; no pre-created legacy `vpsadmin` account.
- Debian Docker Engine and Compose V2 with both `docker-compose` and `docker compose` interfaces.
- Tracked SSH, networkd/resolved/timesyncd and 1 GiB LZ4 ZRAM settings.
- Automated tests using disposable overlays, preserving the original artifact.

## Validation

The owner built the final versioned candidate on Zorin and supplied passing output for two independent UEFI boots, NoCloud provisioning, key-based SSH and effective SSH restrictions, Docker container execution, both Compose interfaces, network, ZRAM and unique machine IDs/host keys. Extended checks passed actual NTP synchronization, Docker Hub hello-world/nginx pulls, HTTP responses and reboot with persistent identities, HTTP service recovery and no failed units.

These are owner-executed local results; no independent VM run in the managed authoring environment is claimed. `acceptance.json` binds this evidence to the uploaded image digest. The immutable build-time `build.json` field `boot_smoke_test: not_run` predates the subsequent tests and is retained for provenance.

## Requirements and limitations

- x86_64, QEMU/KVM, virtio devices, UEFI with Secure Boot off; tested with 2 vCPU and 2 GiB RAM.
- NoCloud seed with your public SSH key before first boot. The cloud-provisioned `debian` user has passwordless sudo and Docker access; passwords and direct root SSH login are disabled.
- Other providers/datasources, BIOS boot, ARM and Secure Boot are not validated.
- Packages remain moving Debian Trixie inputs. Byte-for-byte reproducibility is not claimed.
- This is a purpose-configured Debian server image, not a replacement distribution built from scratch.

The v0.1 release and its assets remain unchanged.
