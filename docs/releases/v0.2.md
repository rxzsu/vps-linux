# VPS Linux v0.2 — release notes draft

Status: preparation only. The successfully tested local artifact is still marked `0.2-dev`; a stable v0.2 release has not been published.

## Changes from v0.1

- A source-controlled mmdebstrap/libguestfs build pipeline replaces manual image assembly.
- GPT, 512 MiB EFI partition, ext4 root and fallback UEFI GRUB in an 8 GiB standalone QCOW2.
- Version/package/source metadata and verified SHA256 accompany the generated image.
- cloud-init creates the key-provisioned `debian` user; no pre-created `vpsadmin` account.
- Debian Docker Engine and native Compose V2 support both docker-compose and docker compose.
- Tracked SSH, networkd/resolved/timesyncd and 1 GiB LZ4 ZRAM policy.
- Disposable-overlay acceptance tests cover independent first boots, security, containers, actual NTP sync, external registry/HTTP workloads and reboot persistence.

## Validation

The owner reported successful build, two-instance smoke and extended online/reboot acceptance tests on Zorin for the development candidate. See ../validation.md for exact evidence and remaining provenance/version-promotion steps. No independent VM execution is claimed in the managed authoring environment.

## Compatibility and limitations

x86_64, QEMU/KVM, UEFI with Secure Boot off, virtio devices and NoCloud provisioning. Tested guest profile: 2 vCPU / 2 GiB RAM. No universal cloud-provider compatibility or byte-for-byte reproducibility claim. Package repositories remain moving Debian Trixie inputs.

## Publication checklist

Select a clean stable source revision; promote all version markers consistently; build and test the final candidate; record exact artifact SHA256, package manifest, source provenance and test evidence; then create a new v0.2 release with those assets. Preserve v0.1 assets. Never publish this draft with invented asset hashes or unsupported release claims.
