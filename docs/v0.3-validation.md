# v0.3 operations validation

Source: feature/v0.3-operations. Version remains 0.3-dev; no stable release or image boot is claimed by the following container-only results.

## Executed in the managed Debian 13 container

- ShellCheck and 36 Python safety/configuration/integrity tests: passed.
- Real 8 GiB sparse QCOW2 fixture creation and qemu-img format/integrity checks with QEMU 10.0.13: passed. These fixtures contain no OS and were never booted.
- Real minisign 0.12 signing and verification: valid bundle accepted; changed bytes, a changed signed manifest, unrelated keys, omitted payload checksums, false metadata, unrelated same-count SBOM and fake QCOW2 rejected.
- SPDX namespace changes when content changes; identical explicit inputs produce identical documents. Multiarch identities and architecture=all are preserved without identifier collisions.
- Native apt-config merged-policy test clears both inherited origin lists and admits exactly the Debian security codename/label rule. Runtime checks also read the guest's effective APT configuration.
- Test utilities were extracted locally from Debian packages with hashes checked against a Packages index whose hash was verified against the signed official Trixie InRelease. No host packages, TLS trust or package verification were weakened.

## Not run here

The container is uid 1000 with no sudo/host-root access, mmdebstrap, guestfish or virt-customize. build.sh --check fails safely before creating an image; tests/v0.3-check.sh reports the missing sudo capability. Installing qemu-img for structural fixtures does not supply a full VM build host.

A full Debian bootstrap, v0.3 guest boot, Guest Agent RPC, disk growth/GPT relocation, live service behavior and the extended network/reboot suite are **not run**. The one-command local wrapper is implemented, but its actual full run still requires the developer's Zorin host. Results for v0.2 must not be reused as v0.3 evidence.

Keyless cosign signing/verification and its negative changed-manifest check are configured in the manual Actions job, but are not claimed passed without that job's actual result. Local minisign tests do not validate GitHub OIDC/cosign. No private keys or test VM credentials are committed; no v0.3 release has been published.
