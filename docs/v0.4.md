## Integration

- Build vpsctl on the host with Rust 1.99.0, Cargo.lock and an explicit amd64 target.
- Package records exact source commit/dirty state; image preflight rejects stale
  or dirty packages and verifies the allowed amd64 ELF/documentation payload
  (binary, README/copyright).
- No maintainer scripts, arbitrary config files, symlinks or privileged modes.
- Builder snapshots the validated package in its private work directory, validates
  it again and installs with dpkg in the isolated bootstrap guest. No guest Rust.
- Package is recorded by dpkg, packages.tsv and SPDX (first-party vps-linux PURL).
- build.json binds vpsctl version/commit/package SHA. The .deb is included in
  SHA256SUMS, artifact transfer and publication. Publisher re-downloads and verifies
  the uploaded package before making the draft public, as well as the QCOW2.
- New source changes require rebuilding the package; cached compiler outputs are
  reused by Cargo, but an old prebuilt package is not accepted.

## Testing

Existing image acceptance plus tests/verify-vpsctl-guest.py checks both VM clones
and the rebooted instance: installed version/provenance, info/status/network JSON,
non-root/root effective security policy, offline doctor, noninteractive behavior,
and a real PTY TUI session with terminal restoration.

Rootless fixtures validate actual Debian packages and a v0.5 QCOW2/SBOM bundle;
wrong source/version, dirty builds, hooks, setuid binaries, unexpected payload,
missing checksum coverage and mismatching installed package versions are rejected.
These fixtures are not substitutes for the full VM run.
